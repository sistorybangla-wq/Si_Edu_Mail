# 🎓 .EDU Email Generator Bot

Telegram bot that generates real `@liberty.edu` emails automatically.

## Features
- ✅ 100% anonymous - No user data stored
- ✅ Zero input required - Everything auto-generates
- ✅ Real .edu email with working inbox
- ✅ Owner approval system
- ✅ Balance management

## Deploy on Render
1. Fork this repo
2. Create Web Service on render.com
3. Add environment variables:
   - `BOT_TOKEN`
   - `OWNER_ID`
4. Deploy!

## Commands
- `/generate` - Generate .edu email
- `/status` - Check status
- `/balance` - Check balance
- Admin: `/approve`, `/addbalance`, `/stats`
